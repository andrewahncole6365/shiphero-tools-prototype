## Project Overview

ShipHero Academy Tools is a browser-accessible prototype built around a central landing page. From that page, visitors can launch either of two independent Academy tools. The tools share an Academy-inspired visual system while retaining their own JavaScript-based interactions.

Since the project is made for static hosting, it can be published with GitHub Pages and does not depend on a server-side runtime. It can serve as a compact demonstration, a starting point for an interface, or an area for developing Academy tool ideas.

## Frequently Asked Questions

### How do I access the hosted prototype?

Open the published project URL:

[Open ShipHero Academy Tools](https://andrewahncole6365.github.io/shiphero-tools-prototype/)

### Is a backend required?

No. This prototype is arranged as a static website delivered directly to the browser, and no backend is specified.

### How can I change either tool?

Edit the applicable HTML, CSS, and JavaScript files, verify the result locally, then publish the repository again through GitHub Pages.

### What can I check when a tool fails to load?

Make sure JavaScript is enabled, inspect the browser developer console for path or file errors, and confirm that every referenced asset has been committed to the repository.

### How are new changes deployed?

Push the changes to the branch and directory selected in the GitHub Pages settings. After deployment finishes, reload the hosted URL to see the updated prototype.

### Where does the configuration live?

Project behavior and presentation settings are kept in the static source files, while hosting-related options are maintained in the repository's GitHub Pages configuration.
